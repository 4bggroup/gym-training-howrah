LOHAA — HOWRAH GYM WEBSITE — DESIGN & LEAD DESK UPDATE 4

প্রথমে ZIP-টি Extract All করুন। ZIP-এর ভিতর থেকেই HTML চালাবেন না।

১. ডিজাইন দেখতে: website/index.html ডাবল-ক্লিক করুন।
   ছবি, CSS, fonts ও animation সব local। Internet দরকার নেই।
   এই অবস্থায় lead form Preview mode দেখাবে; enquiry download হবে, submit হবে না।

২. Lead form দিয়ে enquiry সংরক্ষণ করতে:
   Node.js 20 বা তার পরের সংস্করণ থাকতে হবে।
   START-WINDOWS.bat ডাবল-ক্লিক করুন।
   ব্রাউজারে http://127.0.0.1:3000 খুলুন।
   এবার form-এ Send my enquiry দেখাবে।
   Enquiry জমা হলে storage/leads.jsonl-এ সংরক্ষিত হবে।
   Window চালু রাখুন। বন্ধ করতে Ctrl+C চাপুন।

৩. Lead CSV পেতে: EXPORT-LEADS-WINDOWS.bat চালান।
   storage/leads-export.csv Excel-এ খুলতে পারবেন।

৪. Owner dashboard চালু করতে:
   প্রথমে SETUP-ADMIN-WINDOWS.bat চালিয়ে ১২ বা তার বেশি অক্ষরের password দিন।
   Password টাইপ করার সময় দেখা যাবে না। কোনো default password নেই।
   Server restart করে http://127.0.0.1:3000/admin.html খুলুন।
   Search, status filter, notes ও CSV export পাবেন।
   Status/notes save করলে customer-কে message যাবে না।
